Python-Based Mini Compiler

A Python-based Mini Compiler developed as a Computer Science and Technology project. The project demonstrates the fundamental phases of compiler design, including lexical analysis, syntax analysis, symbol table management, intermediate code generation, and code optimization.

Features

Lexical Analysis: Identifies tokens from source code.

Syntax Analysis: Parses source code according to grammar rules.

Symbol Table: Manages identifiers and related information.

Intermediate Code Generation: Generates an intermediate representation of the program.

Code Optimization: Applies optimization techniques to intermediate code.

Parser Output: Displays parsing results for supported input programs.
